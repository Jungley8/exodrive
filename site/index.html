Make room on the disk that came with your Mac.

Exodrive moves a developer cache to an external drive. It checks every byte first. It frees the space only after the copy passes.

Every move runs the same five steps

The order is the safety: the local cache stays until the copy is proven.

  1. Copy

    The cache goes to the drive with its permissions and times.

  2. Check

    Exodrive reads every file on both sides. One different byte stops the move.

  3. Record

    The move goes into a ledger, so a move back finds it later.

  4. Switch

    The tool reads the new path at its next start.

  5. Free

    Exodrive deletes the local copy. The space is yours again.

Exodrive stops before it damages data

Each rule refuses the move. None of them continues in a weaker mode.

RuleWhat happens
Filesystem Exodrive uses APFS, HFS+, ext2, ext3, ext4, btrfs, zfs, xfs, f2fs, or bcachefs. It refuses exFAT, FAT32, and NTFS.
Running tool A package manager or container engine that runs stops the move. Stop it first.
Shell variable A cache path in your shell wins over the tool setting. Exodrive names the variable and stops.
Binaries Exodrive moves caches only. Your binaries stay where they are.
Second move An item in the ledger stays where it is. Move it back first.

Install

Install the newest release with one command:

curl -fsSL https://jungley8.github.io/exodrive/install.sh | sh

The script downloads the archive for this Mac and checks it against SHA256SUMS. A mismatch stops the install. Read it first: install.sh. The bundle is ad-hoc signed, so a download from a browser asks for your confirmation on the first start: right-click the app, then choose Open.

Prefer an archive? Download it from the releases page.

Where Exodrive runs

The promise is narrow on purpose: one platform carries a promise today.

macOS 13 or later

The window ships here. Every test runs here.

Linux

The command line tool builds and runs. CI tests it on Ubuntu.

Windows

The window builds from source. No build ships and no test covers it.
