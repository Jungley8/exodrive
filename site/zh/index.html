给内置磁盘腾出空间。

Exodrive 把开发缓存搬到外接磁盘。它先逐字节校验副本，校验通过后才释放本机空间。

下载 阅读文档

Apache 2.0，免费使用。macOS 版需要 macOS 13 或更高版本。

每次迁移都走同样的五步

顺序就是安全保证：副本被证实之前，本机缓存一字节都不动。

  1. 拷贝

    缓存复制到磁盘，保留权限和修改时间。

  2. 校验

    Exodrive 读取两侧的每个文件。有一个字节不同，迁移立即停止。

  3. 记账

    这次迁移写入账本，将来搬回时按账本找到它。

  4. 切换

    工具下次启动时读取新路径。

  5. 回收

    Exodrive 删除本机副本。空间回到你手里。

数据可能受损时，Exodrive 直接停下

每条规则都是拒绝执行。没有任何一条会退化为弱安全模式。

规则发生什么
文件系统 只接受 APFS、HFS+、ext2、ext3、ext4、btrfs、zfs、xfs、f2fs、bcachefs、NTFS。拒绝 exFAT、FAT32。
程序在运行 包管理器或容器引擎正在运行时，迁移停止。先停止该程序。
shell 变量 shell 里的缓存路径会盖过工具设置。Exodrive 指出变量名并停止。
二进制 只搬缓存。你的可执行文件留在原处。
重复迁移 账本里已有的条目不再迁移。先把它搬回来。

安装

一条命令安装最新版本：

curl -fsSL https://jungley8.github.io/exodrive/install.sh | sh

Windows 上在 PowerShell 里运行：

irm https://jungley8.github.io/exodrive/install.ps1 | iex

脚本下载对应本机的包，并用 SHA256SUMS 校验；校验不通过就停止。运行前可以先读脚本： install.sh 或 install.ps1。 macOS 应用为 ad-hoc 签名，从浏览器下载的文件首次打开会要求确认：右键点按应用，选择「打开」。

也可以从发布页直接下载压缩包。
